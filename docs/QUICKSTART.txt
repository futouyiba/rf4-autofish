RF4 自动钓鱼 v1.0.0 —— 三步开钓
================================

【准备工作】
  1) 游戏已进世界，人站在水边，屏幕底部出现「钓具准备好，可以抛掷一下」
  2) 游戏窗口标题必须是：Russian Fishing 4
  3) 画面 16:9（1920x1080 最稳）

【开钓】
  1) 双击 RF4AutoFish.exe
     —— 单文件版第一次启动要解包，等 5~15 秒，别以为卡死了
     —— 面板会自动贴到游戏窗口右边
  2) 点「启动后台（离线时）」       状态：离线 -> PROBING
  3) 点「开始/恢复自动」            模式：OBSERVE -> AUTO，开始抛竿

  正常会一直循环：抛竿 -> 等咬钩 -> 中鱼 -> 搏鱼 -> 入护 -> 再抛
  面板 kept 每 +1 就是一条鱼进护

【想停】
  立即停止   Ctrl+Alt+Shift+F10   马上停
  本条停     Ctrl+Alt+Shift+F9    打完手上这条再停（不丢鱼）
  紧急停止   面板按钮             强杀 + 松开所有按键（鼠标失控时用）

  注意：关掉面板不会停钓鱼，面板只是遥控器


常见情况怎么办
--------------
* 一直「离线」            后台没起来。点「启动后台」；还不行看日志：
                          Win+R 输入 %LOCALAPPDATA%\RF4AutoFish
* 一直 PROBING 不抛竿     检查上面三条准备工作；多半是没有「钓具准备好」
* 等了很久没鱼            可能饵没了 / 夜里鱼图标看不见 / 钓点没鱼
* 一直搏鱼拉不上来        超过 4 分钟会自动收线重抛（判为挂草）；
                          老挂草就换个朝向或钓点
* 底部没有「钓具准备好」  线或钩断了，进游戏重新装钓组
* 杀毒软件报毒            打包程序的常见误报，加信任即可
* 启动慢                 单文件版每次启动都要解包约 204MB，5~15 秒正常


使用须知
--------
* 运行时会接管真实键盘鼠标（F5/F6/左右键/滚轮），
  请保持游戏窗口在前台，不要同时手动操作
* 不支持自动补饵、自动换钩、自动换钓点 —— 这些需要你手动处理
* 仅供本地私服/单机学习使用，不含游戏本体与账号
