# Windows 绿色版（exe）使用说明

一个 exe 搞定：双击 → 控制面板吸附在游戏窗口右侧 → 点按钮开钓 / 收工。
不需要装 Python、不需要装依赖、不用命令行。

> 面板只负责**发指令和看状态**，抛竿/搏鱼的那套逻辑跑在独立的后台进程里。
> 所以**关掉面板不会停掉钓鱼**，要停请点「立即停止」或「紧急停止」。

---

## 1. 下载与解压

1. 到 [Releases](../../releases) 下载最新的 `RF4AutoFish-vX.Y.Z-win64.zip`（约 70 MB，解压后约 215 MB）。
2. 解压到一个**路径不含中文和空格**的目录，例如 `D:\RF4AutoFish\`。
3. 目录结构应该是这样（`_internal` 必须和 exe 同级，**不要单独把 exe 拿出来**）：

```
D:\RF4AutoFish\
├─ RF4AutoFish.exe
└─ _internal\          ← 依赖与模板，整个目录都要在
```

> 解压后如果杀毒软件报「未知程序」，是 PyInstaller 打包的常见误报，
> 加信任即可；也可以按 [第 9 节](#9-从源码自己打包) 自己构建。

---

## 2. 第一次开钓（三步）

1. **先开游戏**，走进世界、站到水边，确认底部出现「钓具准备好…」。
   - 游戏窗口标题必须是 `Russian Fishing 4`。
   - 窗口分辨率按 **1920×1080** 标定（全屏或窗口化都行，但画面比例要 16:9）。
2. **双击 `RF4AutoFish.exe`**。面板会贴到游戏窗口右侧 8 像素的位置。
   - 拖动面板顶部的标题栏可以挪位置。
   - 勾掉底部「跟随游戏」就不再自动吸附；重新勾上会立刻贴回去。
3. 面板里点 **「启动后台（离线时）」** → 状态从 `离线` 变成 `PROBING`（在找钓具/线状态）。
   然后点 **「开始/恢复自动」** → 模式从 `OBSERVE` 变成 `AUTO`，开始抛竿。

> 后台启动时默认是 **OBSERVE（只看不动手）**。必须显式点「开始/恢复自动」
> 或按 `Ctrl+Alt+Shift+F7` 才会真正接管键鼠——这是防呆设计，别以为它卡住了。

## 3. 面板上每一行是什么意思

| 行 | 含义 |
|---|---|
| **状态** | 状态机当前状态：`PROBING` 找点、`WAIT_BITE` 等咬钩、`CALIBRATING` 校准、`FIGHT` 搏鱼、`LAND` 上岸、`SETTLE` 结算、`FAULT` 故障 |
| **模式** | `OBSERVE` 只看不动手；`AUTO` 自动操作；`BLOCKED` 被前置条件挡住 |
| **原因** | 进入当前状态的理由（诊断用，例如 `protocol_fight` 表示协议判定中鱼） |
| **状态/鱼 elapsed** | 当前状态已持续秒数 / 本条鱼已搏斗秒数 |
| **cur / 可信度** | 摩擦片档位（29 为顶格）/ 该读数的可信度 |
| **bar / tier** | 力度条等级 / 色带档 |
| **ring** | 线杯圆环读数（`unknown` 表示夜间等场景读不到，正常） |
| **desired / emitted** | 期望按下的键 / 实际发出的键（卡键时看这里） |
| **kept** | 本次运行成功入护的鱼数 |
| **last_error** | 最近一次错误的简短描述 |
| **NET待确认/心跳** | 是否需要人工确认抄网 / 后台心跳年龄（>2 秒说明后台卡住或已死） |
| **回执** | 上一次点击按钮的结果 |

状态行的颜色：绿色 = 在线且在跑，黄色 = 有告警，红色 = 离线或故障。

## 4. 按钮与热键

按钮上写的是**裸键名**，实际热键都是 `Ctrl+Alt+Shift+Fn` 组合（单独按 F6 不会触发，不会干扰游戏里的抬竿键）：

| 按钮 | 热键 | 作用 |
|---|---|---|
| 启动后台（离线时） | `Ctrl+Alt+Shift+F6` | 拉起后台进程（等价于 `bot_ctl start`） |
| 开始/恢复自动 | `Ctrl+Alt+Shift+F7` | 授权自动接管（OBSERVE → AUTO） |
| 仅观察 | `Ctrl+Alt+Shift+F8` | 收回授权，只观察不动键 |
| 立即停止 | `Ctrl+Alt+Shift+F10` | 立刻停，不等当前这条鱼 |
| 本条结束后停 | `Ctrl+Alt+Shift+F9` | 打完当前这条再停（不会断线丢鱼） |
| 确认钓具就绪 | — | 误判「没准备好」时人工放行一次 |
| 我已手动收网 | — | 抄网卡住、你手动收完之后点一下 |
| 紧急停止 | — | 弹确认后强杀后台并松开所有键（鼠标失控时用） |

> 「立即停止」只让状态机停下来并释放按键，**后台进程还在**（心跳仍更新）。
> 要彻底结束进程用「紧急停止」，或者直接关掉游戏后重启面板。

## 5. 文件都在哪

exe 只读自己目录；**运行时产生的文件全部写到** `%LOCALAPPDATA%\RF4AutoFish\`：

| 文件 | 内容 |
|---|---|
| `_bridge.log` | 主日志（状态迁移、协议判据、每次抛竿/收线） |
| `autofish.endpoint.json` | 面板与后台通信的本地端点（含 token，别外传） |
| `run.pid` / `autofish.process.json` | 后台进程身份，`stop` 靠它精确杀进程 |
| `selftest.txt` | `--selftest` 的自检结果 |

想看日志：`Win+R` → 输入 `%LOCALAPPDATA%\RF4AutoFish` → 回车。

## 6. 命令行（进阶）

同一个 exe 支持切角色，方便写脚本或在计划任务里用：

```bat
RF4AutoFish.exe --version                     :: 版本号
RF4AutoFish.exe --selftest                    :: 自检（依赖/资源/路径），结果写 selftest.txt
RF4AutoFish.exe --ctl status                  :: 后台是否在跑
RF4AutoFish.exe --ctl start                   :: 启动后台（前台阻塞，日志进 _bridge.log）
RF4AutoFish.exe --ctl stop                    :: 停止后台
RF4AutoFish.exe --ctl emergency-stop          :: 强杀并松键
RF4AutoFish.exe --bot --pidfile ... --endpoint ...   :: 直接跑后台（调试用）
```

## 7. 可选：让 OCR 生效

面板/后台自带的功能（抛竿、搏鱼、调档、协议判据）**不需要 OCR**。
只有「读地图坐标自动走回钓位」「读鱼护数量」这类功能依赖 PaddleOCR 服务。

需要的话，把项目里的 `venv-ocr` 目录整个复制到 exe 同级：

```
D:\RF4AutoFish\
├─ RF4AutoFish.exe
├─ _internal\
└─ venv-ocr\        ← 可选，约 360 MB
```

没有它也不会报错，只是那些读字功能返回空。

## 8. 常见问题

**状态一直是「离线（endpoint unavailable）」**
后台没起来。先点「启动后台（离线时）」；若回执报错，看 `%LOCALAPPDATA%\RF4AutoFish\_bridge.log` 最后几行。

**回执说「已请求启动后台」但状态还是离线**
后台启动失败退出。常见原因：游戏没开 / 窗口标题不是 `Russian Fishing 4` /
画面不是 1920×1080 / 找不到 `ready_cn.png`（说明 `_internal` 被拆散了）。

**状态停在 `PROBING` 很久，不抛竿**
先看 `ring` 和 `回执`。如果是「服务器掉线」，游戏画面会冻结在世界、按键无响应、
日志里也没有新事件——这不是 bot 的问题，重启游戏即可。

**面板挡住了游戏/跑到屏幕外**
拖动标题栏挪回来；或者勾掉「跟随游戏」后手动摆位置。

**换一台电脑 / 换一个分辨率**
把整个 `RF4AutoFish` 目录拷过去即可，数据目录会重新生成。
分辨率不是 1920×1080 需要重新标定（见 `docs/` 里的实测文档），当前版本按 1920×1080 硬编码。

**面板关了，鱼还在钓？**
正常。面板是遥控器，后台是实体。关面板不会停后台。

## 9. 从源码自己打包

```bash
cd bot
bash build_exe.sh          # 装 PyInstaller（缺的话）→ 构建 → 打 zip
ls dist/RF4AutoFish-v1.0.0-win64.zip
```

构建脚本做的事：调 `PyInstaller rf4autofish.spec`（onedir），
再把 `dist/RF4AutoFish/` 压成 zip。spec 里已经把 `rf4s` 快照、`static/` 模板、
`config.yaml` 一并收进去，不需要额外的 `vendor/` 目录。

---

## 10. 边界与免责

* 只适用于**本地私服/单机**学习用途，不包含游戏本体与账号信息。
* 会接管真实键鼠（F5/F6/左右键/滚轮），请确保运行期间游戏窗口在前台，
  并且**不要同时手动操作**。
* 拿不准时用「紧急停止」；它优先松键，其次才是杀进程。
