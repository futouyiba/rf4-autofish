# RF4 自动钓鱼 · RF4S 运行时补丁适配层

给第三方汉化客户端用的底层钓鱼自动化。**不改 RF4S 源码**，在运行时打补丁把它的
判据、流程、输入通道替换掉，实现一条能长时间自己跑的底钓循环：

```
抛竿 → 等咬钩 → 搏鱼（按住左右键 + 实时调摩擦片）→ 入护 → 重抛
```

卡住的时候不再硬扛，而是把现场交给外部 Agent 判断后继续。

> ⚠️ 仅供个人学习与单机使用。本仓库**不包含**游戏本体、第三方 RF4S 源码，也不含任何账号/服务器信息。

---

## 它能做什么

- **单竿底钓全自动**：抛竿（Shift + 左键 1 秒）→ 等 2.5 秒 → 短按左键关线杯 → 等咬钩
- **咬钩判据**：底部圆形鱼图标是否出现（像素级二值信号，不是模板匹配）
- **搏鱼**：左右键全程按住，同时按 10 秒窗口规则调整摩擦片
- **入护**：点结算框里的「入护」按钮（**不是按空格**，见下）
- **异常接管**：卡在菜单/弹窗、线长圆环卡住、线快被拉空 —— 上报现场给 Agent，等指令

---

## 为什么需要这一层

目标客户端有几个东西和上游对不上，硬改源码不好维护，所以全部做成运行时 patch：

| 问题 | 现象 | 处理 |
|---|---|---|
| 独占渲染 | `ImageGrab` / `mss` 截图全黑 | 改用 `PrintWindow` 合成虚拟桌面 |
| 鼠标注入无效 | `mouse_event` 合成的事件被丢弃 | 键鼠改走 `SendInput` / scancode（F5=基本操作，F6=抬竿） |
| 中文界面 | `ready.png` / `wheel.png` 模板匹配不到 | 换等价 HUD 判据（无鱼图标 + 无结算框） |
| 空格一键两用 | 空格既是"入护"又是"使用/收起抄网" | 入护改**点按钮**；抄网走独立的 PageDown |
| 结算框位置浮动 | 奖励行数不同，按钮上下移动 | 动态扫边框定位按钮 |

## 三个核心判据

### 1. 咬钩 = 圆形鱼图标出现

底部「剩余耐力」左边那个圆形鱼图标，是**二值信号**：

| 状态 | 外环白色像素数（`V>=238 & S<=28`，半径 9~14） |
|---|---|
| 有鱼咬钩 | 110 ~ 133 |
| 没有鱼 | 0 ~ 22 |

阈值取 60。比"力度条出现颜色"可靠得多——力度条是半透明叠在 3D 场景上的，
背景（沙地、红色格纹袖子）会透上来，没有鱼的时候也能读出彩色。

### 2. 线长 = 线杯图标外圈的进度环

鱼指标那一排的线杯图标，外圈是一圈进度环：收满 ≈ 97~99% 亮，被鱼拉出线会掉下来。
采样半径是 **13~15**（内圈 10~12 是图标图案，会把比例带偏）。

另外带了**可读性门控**：整圈最亮的角度都不过阈值 → 说明图标根本没画出来
（HUD 被菜单/弹窗盖住）→ 返回 `-1`，不参与判断。否则菜单一开就会被误判成"线空到 0%"。

### 3. 摩擦片 = 脚本内状态变量

摩擦档位在屏幕上**没有读数**，只能靠"滚了几格"自己记：

| 阶段 | 做法 |
|---|---|
| 抛竿前 | 绝对校准：向上滚满 30 档，再退回 17（唯一允许"顶满"的时候） |
| 搏鱼中 | 增量：维护 `cur`，算 `delta = target - cur`，只滚 `abs(delta)` 格 |

规则：

| 条件 | 动作 |
|---|---|
| 最近 10 秒**只要有一帧到红** | 立刻降 1/3（`cur - cur//3`，17 → 12） |
| 最近 10 秒**全是绿** | 升 1/5（`cur + cur//5`，17 → 20） |
| 只有黄/橙 | 不动 |

上限 29。**红线必须立刻降**——早先的版本要等观察窗口走完才降，等于红了还能再扛 10 秒，直接断线。

## Agent 接管通道

脚本不把异常处理写死，卡住就交出控制权：

```
发现异常 → 截图 + 状态 JSON 落盘 _stuck/ → 轮询 _stuck/cmd.json → 执行 → 回到循环
```

触发点：

| 类型 | 条件 |
|---|---|
| `hud_hidden` | HUD 连续 15 秒读不到（菜单 / 能力解锁弹窗） |
| `line_ring_high_stuck` | 线长 ≥90% 卡住 30 秒仍不结算 |
| `line_ring_low` | 线长 ≤10%（线快被拉空） |

指令格式（`agentctl.py` 可以直接下）：

```json
{"action": "click", "x": 960, "y": 810}
{"action": "keys",  "keys": ["esc"]}
{"action": "hold",  "keys": ["f5", "f6"], "secs": 2.0}
{"action": "resume"}  /  {"action": "quit"}
```

排队型弹窗（能力解锁/升级/技能点，长得一模一样、点掉一个立刻弹下一个）会**先自动连点清理**，
清不掉才上报——不然每次升级都要人介入。

## 准备

1. **游戏窗口**必须是 1920x1080 客户区（脚本会按这个尺寸调整并校验）
2. **键位映射**（游戏内 设置 → 控制）：

   | 功能 | 槽位 |
   |---|---|
   | 基本操作 | 鼠标左键 / **F5** |
   | 必选其一的操作 | 鼠标右键 / **F6** |
   | 使用/收起抄网 | Space / **PD (PageDown)** |

2. **Python 3.12** 与依赖：

   ```bash
   pip install pywin32 pillow numpy opencv-python pyautogui pydirectinput
   ```

3. **第三方 RF4S**（本仓库**不分发**，需自行获取）：

   ```bash
   git clone <RussianFishing4Script 仓库> refs/RussianFishing4Script
   # 或用环境变量指定：set RF4S_REF=D:\path\to\RussianFishing4Script
   ```

## 运行

```bash
python rf4s_adapter.py bot -N BOTTOM
```

Windows 上也可以用 `bot_ctl.py` 做开关：

```bash
python bot_ctl.py start     # 前台运行
python bot_ctl.py stop      # 停止并释放所有按键
python bot_ctl.py status
```

## 目录

```
rf4s_adapter.py   主适配层：截图/输入/检测/流程 patch，全部集中在这里
rf4_focus.py      窗口置前与点击（SendInput 绝对坐标）
agent_hook.py     Agent 接管通道：上报现场、轮询指令、执行动作
agentctl.py       命令行下发指令（click / keys / hold / resume / quit）
bot_ctl.py        启停控制（PID 跟踪、进程树终止、按键释放）
```

## 已知限制

- 只适配 1920x1080 客户区，坐标是硬编码的
- 只写了底钓单竿，海钓/路亚没有
- 线长圆环的低值区间（<10%）还没有足够实测样本，阈值是保守估计
- 结算框按钮位置靠"扫亮线边框"推断，UI 大改就会失效
- 中文客户端专用：`ready.png`、`wheel.png` 这些英文模板匹配不到，才走了等价判据
